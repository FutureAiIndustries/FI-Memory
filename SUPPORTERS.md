# Supporters

This file credits the people who supported FIMemory's development and who
asked to be named. It is empty right now because there is nobody to list yet.
That is the honest state of the file, not a build that came out wrong, and
there are no placeholder names in it standing in for people who do not exist.

## How a name gets here

Credit is opt-in, and the choice belongs to the person being credited. Three
answers, all of them fine: your real name, a handle, or nothing at all. No
name is added without permission, and declining costs you nothing.

## How to support

Through GitHub Sponsors, if you want to. That is the whole mechanism, and it is
the only one.

Nothing is sold here. There is no paid tier, and there is no build of FIMemory
that does more than the one you already have. Sponsoring funds the work and puts
your name in this file if you want it here. It gets you nothing else, because
there is nothing else to get.

## What a name here does not do

FIMemory is free to everyone, listed here or not. A name in this file changes
nothing about the software on your disk. There is no feature behind it and no
check anywhere in the runtime that reads it. It is a thank-you in a text file,
and it ships inside the package so the credit travels with the software.

## Why this is not in LICENSE.md

`LICENSE.md` is a legal instrument, and tooling parses it to work out which
terms apply to a project. A growing list of names in that file corrupts that
detection, and it would mean editing the licence text every time somebody new
says yes. So the licence stays a licence, and the thank-you stays a thank-you.
